Reminder:

All data were harmonized to ug/m3 using conversion equations and data below the method detection limit were substituted. These fall into two cases: 1) where the compound was not detected and 2) when the compound was detected but below the laboratory’s detection limit. In the first case, a zero was substituted for these values (to avoid biasing summary statistics high). In the second case, the value of half of the detection limit was substituted. Since the value is somewhere between zero and the detection limit, this approach essentially biases the results by a known amount.

Note 1: Data displayed in the summary statistics table are in scientific notation. Scientific notation is a shorthand to be able to display data that have a wide range of values from high to very small. This method involves two parts, the number in the first part and then the power of 10. The first part tells us the number and then the power of 10 tells us which way and how many decimal places to move the decimal point.

Example: 7,500 in scientific notation would be 7.5 x 103
